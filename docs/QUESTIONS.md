# DPDP Compass — Questions

These questions define the core questions DPDP Compass should be able to answer.

1. What information must a privacy notice contain under the DPDP Act and final DPDP Rules?

2. When is consent required for processing personal data, and what makes consent valid?

3. What additional requirements apply when processing the personal data of children?

4. What does a Data Fiduciary need to do when a personal data breach occurs?

5. When do the different DPDP duties and Rules come into force?

6. Which DPDP requirements are **not yet in force** on a given date?

7. How can a startup determine whether a particular requirement comes from the final DPDP Rules or only from the earlier draft Rules?

8. When does a Consent Manager requirement become applicable?

9. What records and evidence should an organisation maintain to demonstrate DPDP compliance?

10. Has a particular personal data breach been reported to the Data Protection Board, and what authoritative source confirms this?
